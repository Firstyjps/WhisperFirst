นโยบายความเป็นส่วนตัว

WhisperFirst · ปรับปรุงล่าสุด 17 ต.ค. 2026

WhisperFirst เป็นแอป Mac ที่แจกฟรี ไม่มีบัญชีผู้ใช้ ไม่มีเซิร์ฟเวอร์ของเราอยู่ระหว่างทาง ไม่มี analytics และไม่มีการติดตามใดๆ ทั้งในแอปและบนหน้าเว็บนี้

สิ่งที่ส่งออกจากเครื่อง

  • เสียงที่พูด ส่งตรงจาก Mac ไป Google Gemini ด้วย API key ของคุณเอง เฉพาะตอนที่กดค้างปุ่ม หรือระหว่างโหมดแฮนด์ฟรี (นานสุด 6 นาที)
  • บริบทที่ช่วยให้เขียนถูก ไปพร้อมเสียง: ข้อความ “เกี่ยวกับฉัน” คำในพจนานุกรม คำเรียกวลีลัด ชื่อแอปที่กำลังพิมพ์ และข้อความก่อนเคอร์เซอร์ไม่เกิน 400 ตัวอักษร (ไม่ส่งจาก Terminal ตัวจัดการรหัสผ่าน และช่องรหัสผ่าน)
  • การเรียนรู้คำ: เมื่อคุณแก้คำที่แอปพิมพ์ จะส่งเฉพาะคำที่แก้กับข้อความสั้นๆ รอบจุดนั้นไปให้ Gemini ตัดสินว่าควรจำไหม
  • ElevenLabs (ไม่บังคับ): ถ้าคุณใส่ key ไว้ เสียงจะไปที่ ElevenLabs เฉพาะตอนที่ Gemini ใช้ไม่ได้

ปิดการส่งบริบทและการเรียนรู้คำได้ใน Settings · ถ้าใช้ Private mode จะถอดเสียงด้วย Whisper ในเครื่อง และไม่ส่งอะไรขึ้น cloud เลย

Google และ key แบบฟรี

สิ่งที่ส่งไป Gemini อยู่ภายใต้เงื่อนไขของ Google Gemini API ที่ผูกกับ key ของคุณ ถ้าใช้ key แบบไม่เสียเงิน Google อาจนำข้อมูลไปปรับปรุงบริการ และอาจมีคนตรวจอ่าน — ถ้ากังวล ให้เปิด billing ใน Google AI Studio หรือใช้ Private mode โปรดอ่านเงื่อนไขล่าสุดของ Google ประกอบ

สิ่งที่เก็บในเครื่อง

  • การตั้งค่า พจนานุกรม วลีลัด และ API key อยู่ใน ~/Library/Application Support/WhisperFirst อ่านได้เฉพาะบัญชีผู้ใช้ของคุณ
  • ประวัติการพูด (ถ้าเปิดไว้) เป็นข้อความธรรมดาในโฟลเดอร์เดียวกัน ไม่ถูกสำรองขึ้น Time Machine · เลือกเก็บ 7 วัน 30 วัน ตลอดไป ปิด หรือล้างทั้งหมดได้
  • log อยู่ใน ~/Library/Logs/WhisperFirst บันทึกสถานะการทำงาน ไม่บันทึกสิ่งที่พูด

หน้าเว็บนี้

ไม่มี cookie ไม่มี analytics · server เก็บ access log มาตรฐาน (IP, เวลา, หน้าที่เปิด) ไว้ดูแลระบบเท่านั้น · ฟอนต์โหลดจาก Google Fonts

ลบข้อมูล

ลบแอปและโฟลเดอร์ข้างต้นได้ตามขั้นตอนในหัวข้อ “ถอนการติดตั้งยังไง” บนหน้าแรก ข้อมูลที่ส่งไปแล้วอยู่ภายใต้นโยบายของผู้ให้บริการนั้น (Google / ElevenLabs)
