    ดาวน์โหลด WhisperFirst.dmg เวอร์ชัน ·

    SHA-256

    1. เปิดไฟล์แล้วลากลง Applications

      ดับเบิลคลิก WhisperFirst.dmg ในโฟลเดอร์ Downloads → ลากไอคอน WhisperFirst ไปวางที่โฟลเดอร์ Applications

    2. เปิดครั้งแรก macOS จะเตือน — กดผ่านครั้งเดียว

      เปิด WhisperFirst จาก Applications จะขึ้นว่า “WhisperFirst” Not Opened ให้ทำตามนี้

      1. กด Done (อย่ากด Move to Trash)
      2. เปิด System Settings → Privacy & Security แล้วเลื่อนลงล่างสุด
      3. ตรงข้อความ “WhisperFirst” was blocked… กด Open Anyway
      4. ใส่รหัสผ่าน Mac หรือ Touch ID แล้วกด Open Anyway อีกครั้ง
      5. ไม่เห็นปุ่ม Open Anyway? เปิด WhisperFirst ใหม่อีกครั้ง แล้วกลับไปที่ Privacy & Security ภายใน 1 ชั่วโมง
      💡ที่เตือนเพราะแอปนี้ทำแจกเพื่อน ไม่ได้ลงทะเบียนนักพัฒนากับ Apple ($99/ปี) ไม่ได้แปลว่ามีไวรัส · โค้ดทั้งหมดเปิดให้ดูได้บน GitHub · ทำครั้งเดียว ครั้งต่อไปเปิดได้ปกติ

    3. ให้สิทธิ์ตามไกด์ในแอป

      Microphone — ฟังเสียงตอนกดค้างปุ่ม หรือตอนเปิดแฮนด์ฟรี · Accessibility — รู้ว่ากดปุ่มลัด และพิมพ์ข้อความลงแอปอื่นได้ · ถ้าใช้ลำโพงของจอ (HDMI/DisplayPort) จะมี System Audio Recording เพิ่ม เพื่อเช็กว่าเพลงกำลังเล่นอยู่ไหมก่อนหยุดให้ (ไม่บันทึกเสียง)

      กด Open Settings ในไกด์ → เปิดสวิตช์ WhisperFirst → กลับมาที่ไกด์ จะติ๊กถูกให้เอง

    4. ใส่ Gemini API key (ฟรี)

      เข้า Google AI Studio ด้วยบัญชี Google → กด Create API key → คัดลอก แล้ววางในไกด์ของแอป

      เปิด Google AI Studio ↗

    5. ลองเลย

      คลิกในช่องพิมพ์ไหนก็ได้ กดค้าง Option ขวา พูด แล้วปล่อย 🎉

    WhisperFirst อยู่ที่ไอคอนบน menu bar มุมขวาบน ของจอ (ไม่อยู่ใน Dock) · เปิดไกด์ซ้ำได้จากเมนูนั้น → Welcome Guide… · อยากให้เปิดเองตอนเปิดเครื่อง → Launch at Login
